# WLED Harness v5.3 — Motion Midpoint Release

Base: v5.2 (v5.1 was the faster reference). ESP32 harness with 34-LED P0, 290 mapped logical LEDs, and 592 virtual animation positions.

## Changes

- Echo Chamber: travel-speed midpoint between v5.1 (divisor 185) and v5.2 (1150). v5.3 divisor 319; hue rate also between prior versions.
- Infinite Corridor: divisor 985 (v5.1: 560; v5.2: 4100), approximately halfway in visual travel speed.
- Liquid Mercury: divisor 287 (v5.1: 165; v5.2: 1100).
- Neural Pulse: divisor 166/216/132 for the three moving pulses, midway between v5.1 and v5.2.
- Comet Storm: per-frame motion cadence calculated as the harmonic mean of the former frame intervals, midpoint in LEDs per second.
- Orbital Waltz: orbital period calculated as harmonic mean of the two previous periods for the chosen slider value.
- Phoenix Flight: orbital lap period calculated as harmonic mean of v5.1 and v5.2, retaining pink/purple palette 61 (Pink Candy).
- Wormhole: lap period calculated as harmonic mean of v5.1 and v5.2.
- Electric Organism: no 100%-lit base. Three wide moving neural regions with intentionally dark gaps and bright teal-electric highlighting, targeting approximately half the physical LEDs at once. Coverage varies as the fronts cross.
- Ember Drift: retired, hidden from the effects picker; numerical effect ID remains reserved so stored presets do not shift.
- Starlight Nervous System: entire animation timeline is 20% faster, with continuous colored output retained.

Not modified: Snake safety, ESP-NOW receiver, palettes chosen by users, effect-specific NVS settings, effect IDs, 34-LED P0 physical map and 592-LED virtual animation path. All other effects remain unchanged.

## Install

1. Download the compiled ESP32 binary from the successful GitHub Actions run for this branch or from the ZIP provided in ChatGPT.
2. WLED > Config > Security & Updates > Manual OTA Update; select the .bin.
3. Refresh the UI; Info should show Harness v5.3.
4. Do not reset or erase settings. There is no need to replace ledmap.json if upgrading from v5.2.
